## 仍影响「好用」的点（建议优先级）

### P0 — 让「运行」更稳、更快

| 项 | 现状 | 建议 |
|----|------|------|
| **嵌套 npm+tauri 构建慢** | 生成 app 后 `npm install` + `tauri build --no-bundle`，首次可达分钟级 | 提供「浏览器预览」：只 `npm run build` + 打开 vite preview / data URL，秒级看到界面 |
| **失败原因不直观** | 错误在任务日志里，UI 只显示 summary | 失败时把 `logPreview` 最后 20 行直接贴到 Build 页错误区 |
| **npm/cargo 环境依赖** | 本机没有 Node/Rust 时必失败 | 启动时检测并提示；缺 Node 给出安装引导 |
| **就绪门禁文案是英文** | `blocked by N readiness issues` | 改中文，点条目可跳到对应修复位置 |

### P1 — 编辑手感

| 项 | 建议 |
|----|------|
| 生成 app 的实时预览 | 右侧 Dock 加「预览」页，内嵌 iframe 加载 vite 产物 |
| 构建失败一键重试 | 任务卡上「重试」直接重跑该步 |
| 右键菜单保留常用操作顺序 | 粘贴/复制/删除/绑定放最上，插入区下移 |
| 撤销粒度 | 批量操作（一键运行播种）应可一次撤销 |

### P2 — 项目管理

| 项 | 建议 |
|----|------|
| 最近项目列表 | 启动时列出最近打开，双击进入 |
| 项目模板向导 | 新建时选模板 → 填名称 → 直接进设计 |
| 损坏项目恢复 | `check:project-health` 接到 UI，一键修复 `.nova` |

---

## 建议的「运行」体验目标

```text
点「运行」
  ├─ 已有 exe → 直接启动
  ├─ 无 exe 但有项目 → 保存+生成+构建（进度条+可取消）
  └─ 空项目 → 播种示例 → 同上

  失败 → 红条显示最后 20 行日志 + 「重试」/「打开日志」
  成功 → 自动拉起 exe 或预览窗
```
