# Nova UI Editor 无障碍手测清单（D1）

> 版本：2026-07 · 状态：草案  
> 适用：每轮 UI / 交互改动后的抽测；发版前完整跑一轮  
> 配套：`output/ui-audit/` 文本裁切审计、`output/goal-audit/` 密度审计

---

## 使用方式

1. 本地启动：`npm run tauri:dev`（或 `npm run dev` 浏览器前端）。
2. 按分区勾选；发现问题记入文末记录表，并开 issue / 直接修。
3. 与工作流 A（UI 审计）同轮验收：修完 UI 先跑 `node output/ui-audit/run-ui-text-audit.mjs`，再勾本清单相关项。
4. 默认视口 1440×900；紧凑视口另测 1100×720（对应 A2.6 / D4）。

**结果标记**：`[x]` 通过 · `[!]` 有问题（记入记录表） · `[-]` 本轮跳过 · `[~]` 接受并记录（已知限制）
